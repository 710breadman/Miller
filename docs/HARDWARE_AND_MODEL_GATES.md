# Hardware and model gates

The following cannot be responsibly completed without the local Windows machine,
real media, or an owner decision.

| Gate | Required input | Pass evidence |
|---|---|---|
| Windows install | `D:\_Codex\Miller` | verifier output and capability report |
| RTX 3070 profile | NVIDIA driver/GPU | measured VRAM, load/unload, batch sizes |
| Retrieval winner | approved comics + 100–300 labels | Recall@K, MRR, nDCG, latency report |
| Narration alignment | representative edited narration | word/beat timing review and mismatch fixtures |
| Text removal | representative lettering/art | masks, clean assets, fallback rate, visual review |
| Revideo | Node/Chromium + same render fixture | time, RAM/VRAM, sync, determinism, packaging |
| Resolve | installed supported Resolve | external timeline/media round-trip |
| Distribution | owner license choice | LICENSE, notices, SBOM, model/weight terms |
